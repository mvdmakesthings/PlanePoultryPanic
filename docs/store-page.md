# Store Page Copy

Copy and settings for the itch.io page. Steam is still the launch store (see [game-design-document.md](game-design-document.md#release-and-business)); the itch.io page is for a free prototype or demo and devlogs, to start building an audience early.

Keep the page **Draft** or **Restricted** until the build, cover and screenshots are ready. itch.io puts a page in Most Recent the first time it goes public, and that only happens once.

---

## Tagline

itch.io's "Short description or tagline" field. It shows under the cover in browse and search.

> The chickens took the airport. Catch the last flight out.

Alternates:

- Chickens grounded the world. You still have a flight to catch.
- Outsmart a mushroom-powered chicken uprising and make the last flight out.

## Description

The top of the page body. Keep it this short so the screenshots sit above the fold.

> Glowing mushrooms woke the world's chickens up, and they came for the thing they envied most: flight. The airports fell first.
>
> You're a stranded connecting passenger with an expired boarding pass and one last chance. A final flight is leaving, and the gate is on the far side of a terminal full of chickens.
>
> You can't fight them. Sneak past, sprint when you have the stamina, throw snacks to send a flock off to eat, and turn baggage carts and fire extinguishers against them. Eat a snack when it's safe to patch yourself up.
>
> **Plane Poultry Panic** is a 16-bit, top-down action game you can finish in one sitting. Played with keyboard or gamepad.

Only describe what is in the uploaded build. As features land (bosses, the chiptune soundtrack, difficulty modes, achievements), add them here. itch.io delists pages that claim content that doesn't exist.

## Tags

itch.io allows 10. Checked against itch.io's tag pages in October 2026; "suggested" means itch.io lists it as a suggested tag, which it recommends over free-form ones.

| Tag | Type | Why |
|---|---|---|
| Chicken | Suggested | The hook. A small tag (about 1,400 games), so the game is easy to find in it. |
| Pixel Art | Suggested | Most-browsed visual tag. |
| Top-Down | Suggested | Camera and genre signal. |
| Retro | Suggested | Reaches the *Zombies Ate My Neighbors* audience. |
| 16-bit | Free-form | Established (about 8,000 games) and more precise than Retro. |
| Funny | Suggested | Core pillar. Don't also add Comedy; itch.io counts that as a synonym. |
| Stealth | Suggested | "Outsmart, don't outfight": no direct attack. |
| Short | Suggested | About 30 minutes; a selling point on itch.io. |
| Post-apocalyptic | Suggested | The setting. |
| Singleplayer | Suggested | Broad, but players filter by it. |

Swap-ins if a tag stops fitting: Dark Humor (suggested), Top Down Adventure (suggested), airport (free-form, 62 games).

Don't tag the game's name, Godot, or controller support. itch.io asks for those as metadata, and its guidelines say not to repeat them as tags.

## Metadata

Set these on the Metadata and Edit pages instead of as tags:

- **Kind of project**: Downloadable
- **Classification**: Games
- **Release status**: Prototype (In development once the vertical slice is up)
- **Genre**: Action
- **Made with**: Godot
- **Platforms**: Only the ones the build has been tested on. Start with macOS, and add Windows and Linux after testing them.
- **Inputs**: Keyboard, Xbox controller, Playstation controller (only the pads actually tested)
- **Average session**: About a half-hour
- **Languages**: English
- **AI disclosure**: Fill this in accurately. The sprites are generated by code an AI assistant wrote, so check itch.io's current wording for graphics and code before publishing; itch.io is strictly enforcing this section.
- **Content**: No adult content. Cartoon violence only (chickens vanish in a puff of feathers).
